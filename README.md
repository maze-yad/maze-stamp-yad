# Christmas Nights · Branding by maze

A scroll-animated showcase of the **Christmas Nights by Sulifest** identity, designed by **maze** (creativity meets disruption).

- `index.html` – the whole site: markup, styles and scripts in one file
- `img/` – optimised WebP/JPG assets, mockups, the maze logo (used as a CSS mask) and the favicon

The site is static, so GitHub Pages serves it as-is from the repository root.
